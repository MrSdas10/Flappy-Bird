# 🐦 Flappy Bird: AI-Generated Edition

Welcome to **Flappy Bird: AI Edition** — a Python-based, fully functional clone of the classic Flappy Bird game. This version was **originally generated by me with the help of an AI tool** and then manually customized and refined for optimal performance and gameplay with the help of GitHub Copilot AI Agent.

---

## 🚀 Features

- 🎮 Classic Flappy Bird mechanics with smooth physics.
- 🧠 Fully AI-generated codebase, manually refined for gameplay accuracy.
- 📦 Built using **Pygame** — simple and easy.
- 🌆 Beautiful background and sprite support.
- 🧱 Realistic gravity and flap dynamics.
- 🧠 Pixel-perfect collision detection.
- 📈 Score tracking and high score persistence.
- 🔁 "Start Again" and "Exit" buttons for a full user experience.

## 🧰 Requirements

- Python 3.7+
- [Pygame](https://www.pygame.org/) (`pip install pygame`)
- Image assets:
  - `bird.png`
  - `pipe.png`
  - `background.png`
  - `base.png`

Make sure these assets are in the same directory as your Python script.

---

## 🛠️ Setup & Run

1. **Install dependencies**  
   ```bash
   pip install pygame
   ```

2. **Place required image assets** in the project directory:
   - `bird.png`
   - `pipe.png`
   - `background.png`
   - `base.png`

3. **Run the game**  
   ```bash
   python Flapybird.py
   ```

## 🎮 Controls

- **Flap**: Press `Up Arrow` key or mouse click.
- **Start Again**: Click the "Start Again" button after a game over.
- **Exit**: Click the "Exit" button on the top right corner.
